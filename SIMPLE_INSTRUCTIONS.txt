HOW IT WORKS:
====================================================================

PDF Link Format:
https://staging2.wholesalefencing.com/wp-content/themes/THEME/download-pdf.php?url=ENCODED_PDF_URL&name=FILENAME

Example:
Original URL: https://wholesalefencing.com/wp-content/uploads/2026/03/Vinyl-Brochure.pdf
Proxy URL: https://staging2.wholesalefencing.com/.../download-pdf.php?url=https%3A%2F%2F...&name=Brochure

The proxy:
1. Fetches PDF from ANY URL (main site, staging, external)
2. Sends Content-Disposition: attachment header
3. Forces browser to download instead of open

TROUBLESHOOTING:
====================================================================

If download doesn't work:

1. Check download-pdf.php is uploaded
   Location: /wp-content/themes/YOUR-THEME-NAME/download-pdf.php

2. Test proxy directly:
   https://staging2.wholesalefencing.com/wp-content/themes/THEME/download-pdf.php?url=https://wholesalefencing.com/wp-content/uploads/2026/03/Vinyl-Brochure.pdf&name=Test

3. Check PHP file_get_contents is allowed
   (Some hosts block external file access)

4. Check browser console for errors
   (F12 → Console tab)

5. Try different PDF URL to test
